## 📌 Sobre el proyecto
Este repositorio contiene el código fuente de mi portfolio web interactivo y mi currículum vitae digital. Está diseñado para centralizar mi trayectoria académica en Matemáticas y mi experiencia práctica, orientando mi perfil hacia la programación avanzada, la algoritmia y la ciberseguridad corporativa.

## 🚀 Características destacadas
* **Diseño Responsive:** Interfaz adaptable a cualquier dispositivo con un menú lateral colapsable (Sidebar) optimizado para la experiencia móvil.
* **Soporte Bilingüe (i18n):** Cambio dinámico de idioma (Español / Inglés) implementado en Vanilla JavaScript sin recargar la página.
* **Integración de Contacto Directo:** Enlaces configurados mediante _Deep Linking_ para abrir la interfaz de redacción de Gmail directamente desde el navegador o la aplicación móvil nativa.
* **Estilo Limpio y Analítico:** Uso de CSS personalizado para mantener una estética profesional, corporativa y fácil de escanear.

## 🛠️ Tecnologías y Herramientas
* **Estructura y Estilos:** HTML5 semántico y CSS3 puro (Flexbox, variables CSS, Media Queries).
* **Lógica:** Vanilla JavaScript (ES6+).
* **Iconografía y Vectores:** FontAwesome 6 y SVGs optimizados.
* **Despliegue:** GitHub Pages.
